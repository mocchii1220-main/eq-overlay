# 地震情報をオーバーレイ表示するやつ

地震情報をオーバーレイ表示するアプリケーションです。
※本アプリは開発中のテスト版（ベータ版）となります。

ダウンロードは [こちら](https://github.com/mocchii1220-main/-/releases/tag/v1.0.1pre)
## 利用について

### 配布ファイルの種類

"バージョン名".zip
▷本番環境　実際の地震と同期します。

"バージョン名"-test
▷30秒に一回受信するテスト用です　P2P地震情報APIのサンドボックス環境に従って動作します。

### 使い方
ポータブル版です
1. ダウンロードした **ZIPファイルを右クリックして「すべて展開（解凍）」** します。
2. 展開されたフォルダの中にある **`dist` フォルダ** を開きます。
3. 中にある **`main.exe` をダブルクリック** するとアプリが起動します。

終了する際はターミナルを閉じてください。

スタートアップ登録しておくと何かと便利です。

## ソフトウェアについて

### config.jsonについて
実行ファイルと同じ階層にある`config.json`ですが、現時点では何の役割もありません。プログラムの動作に支障をきたす可能性があるため、基本的に変更しないようお願いします。
