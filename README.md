# 地震情報をオーバーレイ表示するやつ

地震情報をオーバーレイ表示するアプリケーションです。
※本アプリは開発中のテスト版（ベータ版）となります。

ダウンロードは [こちら](https://github.com/mocchii1220-main/-/releases/tag/v1.1.0pre)
## 利用について


### 使い方
ポータブル版です
1. ダウンロードした **ZIPファイルを右クリックして「すべて展開（解凍）」** します。
2. 展開されたフォルダの中にある **`dist` フォルダ** を開きます。
3. 中にある **`main.exe` をダブルクリック** するとアプリが起動します。

終了する際はターミナルを閉じてください。

スタートアップ登録しておくと何かと便利です。

## ソフトウェアについて

### config.jsonについて
v1.1.0以降はdist ディレクトリ内にある config.json を編集することで、動作モードの切り替えや、地域ごとの震度表示を行う最小震度のしきい値を変更できます。 

#### 1. 接続モードの切り替え（テストモード / 通常モード）

"connect_mode" の値を変更することで、本番環境とテスト環境を切り替えることができます。 

* **通常モード　実際の地震と同期します。**: "connect_mode": "normal"
* **テストモード　30秒に一回受信するテスト用です。**: "connect_mode": "sandbox"
※テストモードはP2P地震情報APIのサンドボックス環境に従って動作します。

#### 2. 地域ごとの震度表示をする最小震度の変更

"min_sindo" の数値を変更することで、指定した震度以上の情報のみを地域ごとに表示するようにフィルターをかけることができます。 

* **設定例**: "min_sindo": "30" （震度3以上の場合に表示）

#### 震度と設定値の割り当て一覧

"min_sindo" に指定する数値と、実際の震度の対応表は以下の通りです。 

設定値実際の震度
| 設定値 | 実際の震度 |
| :---: | :--- |
| **70** | 震度７ |
| **60** | 震度６強 |
| **55** | 震度６弱 |
| **50** | 震度５強 |
| **45** | 震度５弱 |
| **40** | 震度４ |
| **30** | 震度３ |
| **20** | 震度２ |
| **10** | 震度１ |
